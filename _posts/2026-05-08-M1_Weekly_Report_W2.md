## 3. Completed Task Briefings

### 3.1 Task 1 — Improve M1 System Design Doc

**Owner:** Diogo Pinhel

The M1 high-level design document has been further refined. The data transmission between modules is now clearly defined, including who transmits to whom, the content being transmitted (overview), and who initiates the transmission. Additionally, module-level SRS has been clarified to define each module's functions, how each function is used, and what other module functionalities are required. The updated document has been published to the team website.

### 3.2 Task 2 — Update Team Website

**Owner:** Diogo Pinhel

The M1 team website has been updated and upgraded with all latest deliverables from Week 2, including the refined high-level design document, updated interface specification, and mid-term presentation materials.

### 3.3 Task 3 — Prepare & Present Mid-Term PPT

**Owner:** Diogo Pinhel

The mid-term presentation has been prepared and delivered. The PPT covered project overview, requirements analysis, system design, prototype demonstration, and future plans. The presentation was successfully delivered at the mid-term meeting as the person in charge of M1.

### 3.4 Task 5 & 6 — Update Interface Specification & Reach Consensus with V2

**Owner:** Costa-Sara

The M1 interface specification document has been updated. Interfaces between M1 and S1, S2, and registration/login user + session (exercise) start between M1 and V2 are now clearly defined. For each interface, the basic information, function, and usage method are documented. Costa-Sara successfully coordinated with the V2 group and reached consensus on the interface specifications, establishing a solid foundation for subsequent joint debugging.

### 3.5 Task 7 — Complete Exercise Page Group

**Owner:** Enhe Zhang

The exercise page group has been completed, consisting of three pages:

- **Sensor Connection Page:** Rebuilt in communication with S1, enabling BLE sensor scanning and connection.
- **Real-Time Exercise Feedback Page:** Displays real-time data feedback during rehabilitation exercises.
- **Exercise End Feedback Page:** Provides summary and feedback after exercise completion.

The prototype introduction document has been updated with an embedded video demonstration.

### 3.6 Task 8 — Collect & Integrate SRS

**Owner:** Wang Yiding

The SRS documents from all six groups have been collected and integrated. The unified terminology now consistently uses "rehabilitation exercises" instead of "rehabilitation sessions." Real-time data feedback use cases have been updated according to the latest S2 changes, and data transmission specifications for M1→V2 sensor format data have been added. Based on the integrated SRS, a comprehensive use-case diagram has been drawn and published.

### 3.7 Task 9 — Fix Prototype Bugs

**Owner:** Wang Yiding

Several bugs in the application prototype have been fixed:

- Fixed the error of duplicate exit buttons in the upper left corner.
- Fixed the error where users did not need to log in again after logging out (session/logic fix).
- Fixed the rendering error of the bottom button on the main page.
